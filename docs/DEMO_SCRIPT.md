# ShadowTrack — демонстрация 3–5 минут

1. Открыть [Monitor](http://localhost:3000/monitor), сетку пяти камер, Play.
   Все реальные видео движутся. Проверить Pause/Seek: clock modes и автоматических перемоток больше нет.
   На первых секундах камер 1/2 человек с сумками имеет один ID 001.
2. Открыть [ID 267 на камере 4](http://localhost:3000/monitor?camera=4&time=1035&clock=estimated&gtime=1035&global=G0211&track=a6ceb1665bfaf1d2c392).
   Кудрявые волосы, полосатый верх, розовые брюки. Клик bbox, затем участники
   на камерах 3 и 5: автоматически один global ID/цвет. `?` — вероятная связь.
3. В Gantt найти `ID 267`: одна строка с участками камер 4/3/5. Клик интервала
   возвращает нужную камеру/время. Пробелы — отсутствие observations.
   Estimated scale не является точным UTC.
4. В Monitor → «Люди» показать движущиеся точки с ID. Один ID — одна точка.
   Положение приблизительное; не заявлять точную скорость или clock offset.
5. На существующей странице «Связи» нажать «Пересчитать»: CPU, с отображением этапов и heartbeat
   (под нагрузкой до нескольких минут), из cache, без YOLO/ByteTrack/рендера. Review не требуется.
   Timeout 120 s учитывает покрытие; в estimated режиме это условное завершение,
   не доказанный физический выход из офиса.
6. Контроль: 24 разобранных cases; 13 однозначных продолжений и 4 отрицательных
   пары — 13/13 и 4/4 на проверенных кадрах. Исправлены temporal contamination
   и nested bbox дубли. Это повторно использованная выборка, не 100% всего MTMC.
7. `/exports`: private short previews и машинные данные всех 144 110 кадров.
   Frame records/PTS первичны, MP4 вторично. 503 локальных фрагмента и 281
   global episodes не равны количеству уникальных физических людей.

Исходные записи, детекции, Time Alignment и старые MP4 неизменны.
Ошибки и ограничения: [MTMC_REPORT.md](MTMC_REPORT.md).

Пользовательский regression: камера 4, 20 s → камера 5, 23 s: один ID 003.
Архив: текущий ID 019 объединяет два фрагмента прежнего ID 288.

Новый regression: архив → ID 002. Семь фрагментов девушки камер 3/5 в одной карточке.
Сравнить вид спереди/со спины и дубли torso/full-body: ID общий автоматически.
Возврат на камере 3 в 22–32 s также связан автоматически; результат остаётся вероятным.


Проверка новых режимов: «Карта» показывает пять номеров камер; «Люди» — точки ID
и список видимых наблюдений. Выбор/снятие выбора человека не сохраняет чужую
подсветку. Показать счётчик при 00:00 и позднем времени: будущие эпизоды не начались.
В «Аналитике» открыть CSV эпизодов: 281 строка, 30 межкамерных эпизодов как поднабор.
Конец записи/недостаточное покрытие не означают подтверждённое завершение.
